# RIVAL Board Review

Run the decision described in the arguments (or the current discussion topic) through all seven board voices, **in this order**, each speaking in its own short section. Do not skip voices, do not reorder, do not merge them.

1. **🟥 The Contrarian** — challenge assumptions: why is this a bad idea? What makes it fail? What are we ignoring? Is there a simpler solution? Argue in good faith against the proposal — no strawmen.
2. **🟦 The First Principles Thinker** — what problem are we actually solving? What assumptions can we remove? How would we build this if fitness apps didn't exist?
3. **🟨 The Expansionist** — how does this get 10x better? Could it define RIVAL or become its own product? What's the moonshot version?
4. **🟩 The Outsider** — how would Apple / Nike / Duolingo / F1 / Netflix / Disney / Airbnb / Spotify approach this? Pick the 2–3 most relevant, don't force all eight.
5. **🟪 The Executor** — what's the MVP? Can it ship in a week? What's V1 and what explicitly waits?
6. **🟧 The Customer Advocate** — does this genuinely improve the user's experience, motivate activity, feel intuitive, create delight (not just another feature)? Would people tell friends about it?
7. **⬛ The Chairman** — summarize the strongest arguments from both sides, identify the real risks, recommend a path forward with the why, and give a **confidence rating /10**. If below 8/10, name exactly what information is missing before committing.

## Grounding rules

- Check the proposal against RIVAL's locked decisions before the board speaks; the board argues within them unless the proposal is explicitly about overturning one:
  - **Ethos**: social fitness identity is the product; effort deserves to be seen, recognised, acknowledged. Always encourage, never pressure or shame.
  - **Positioning**: core = social fitness identity. Nutrition/coaching deferred to a future Pro layer. No public follow graph pre-launch. Growth = invite loops + outbound sharing, not discovery feeds.
  - **Monetization**: cosmetic/volume-only — never gate recognition behind payment.
  - **Product principles gate**: help someone stay consistent; help someone encourage another person; celebrate effort before achievement; reward positive influence over popularity; make fitness more social; reduce loneliness; explainable in one sentence.
- Sequencing risk is a standing Contrarian/Chairman concern: RIVAL is pre-launch — a well-argued second product surface before Layer 1 ships is scope creep.
- Keep each voice tight (3–6 sentences). The value is the collision of angles, not the word count.
- If prior board rulings in Claude's memory cover this topic, cite them instead of re-debating from scratch.
